# 01 思路与方案

## TL;DR
1. **抓包能做到什么**：学习通的视频播放/进度上报、作业列表，全是明文 HTTP(S) 接口（`mooc1.chaoxing.com` 一带），只要登录态在手，就能脱离页面直接调。
2. **推荐架构**：本地 Playwright 应用 + 持久化用户目录。用户自己登录 → 点"一键抓包"→ 程序边监听网络边让用户走一遍真实流程 → 生成接口配置 → 之后**后台静音**自动跑。
3. **视频**：优先"接口重放"（按模板循环 POST 进度），页面根本不真播 → 天然后台+静音+快；失败则退化为"无头播放 + `--mute-audio` + 自动跳下一个"。
4. **作业（无 AI）**：只能靠"本地题库/答案文件精确匹配"或"仅检测 + 记录 + 跳过"。做不到 AI 那种任意题作答——这是需求的硬边界，要提前确认。
5. **现有开源方案已经很多**（见下文调研），最成熟的是 **OCS（ocsjs）**，3.2k star、MIT、原生支持超星、有 Electron 桌面端。**先决定是"直接用/包装 OCS"还是"自己写"**，再动手。

## 一、现状（已核实）
- `https://i.chaoxing.com/base` 未登录 → 302 到 `https://passport2.chaoxing.com/login?fid=12&refer=...&space=2`。
- 登录页支持：账号密码、**学习通 APP 扫码**、验证码登录、其他方式。
- 结论：抓"视频/作业"接口**必须有登录态**，所以"一键抓包"必须发生在用户登录之后（与用户描述一致）。

## 二、目标流程（用户版）
```
启动应用
  └─ 打开浏览器（持久化目录 userdata/，启动参数 --mute-audio）
      └─ 用户手动登录（扫码/账号）
          └─ 点「一键抓包」
              └─ 程序开始记录网络，提示用户：随便点开一节视频课、翻一页作业
                  └─ 自动提取接口 + 参数模板 → captures/ + config/endpoints.json
                      └─ 点「开始刷课」
                          └─ 后台静音跑：视频任务点 → 作业任务点 → 下一个 → ... 直到无未完成
```

## 三、技术方案（三条路，可组合）

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 接口重放** | 从抓包得到进度上报接口 + 参数模板，用 `requests`/`aiohttp` 直接循环上报 | 真后台、真静音、快、稳 | 依赖接口稳定；有反作弊风险 |
| **B. 浏览器自动化** | Playwright 无头/最小窗口，`--mute-audio`，DOM 点播放，`on('response')` 监听 | 贴合真实用户、反检测好 | 比 A 慢；仍有窗口/资源开销 |
| **C. 油猴脚本** | 直接装现成脚本（OCS 等） | 0 开发量、社区维护 | 只在浏览器里跑，不是"本地小应用" |

**推荐：A + B 混合** —— 用 B 拿到登录态并做抓包，用 A 跑批量视频；A 失败自动回退到 B。

## 四、抓包计划（正式开工时执行）
监听并落盘以下域名的请求（请求头 + 载荷 + 响应体）：
- `mooc1.chaoxing.com`
  - `/mycourse/studentstudy` —— 章节学习页
  - `/ananas/modules/video/index.html` —— 视频播放器 iframe
  - `/multimedia/log/a/{courseId}/{clazzId}` —— **视频进度上报（核心）**
  - `/work/...` —— 作业相关
- `mooc2-ans.chaoxing.com` —— 课程/章节列表
- `passport2.chaoxing.com` —— 登录

需要的产物：
1. `config/endpoints.json`：接口 URL 模板 + 必填参数（`courseId`,`clazzId`,`chapterId`,`objectId`,`jobid`,`enc`,`token`…）+ 请求头 + 成功判据（如响应里的 `isPassed`）。
2. `20-captures/*.har`：完整原始证据。
3. 参数从哪个页面 DOM 里取（`enc`/`token` 这类每个 course 都变的）→ 记录提取选择器。

## 五、作业（无 AI 的现实边界）
- 学习通"作业"= `work` 模块，提交前需要**答案**。
- 无 AI ⇒ 只能：
  - (a) 用本地题库文件（题干→答案）精确/模糊匹配；
  - (b) 只识别出"这是作业/测验"并**跳过 + 记入报告**，由用户自己答。
- ⚠️ 需求里"自动识别作业然后自动帮刷"如果不含题库，实际只能做到 (b)。**开工前必须确认走哪条。**

## 六、风险与合规提示
- 平台有反作弊：上报心跳间隔、倍速、并发、设备指纹都可能被记录；**异常刷课可能影响成绩/学籍**。
- 这是用户**自己账号**上的自动化，但可能违反平台用户协议。使用者自负后果。
- 建议：限制速率、模拟真实节奏、先小范围试。

## 七、现有开源方案调研（preflight，2026-09-21 联网核实）
| 项目 | star | 形态 | 说明 |
|---|---|---|---|
| [ocsjs/ocsjs](https://github.com/ocsjs/ocsjs) | **3.2k** | 油猴/脚本猫 + Electron 桌面端，MIT | 最成熟，原生支持超星/智慧树/职教云等，持续维护 |
| [Memory2314/XuexitongJSFork](https://github.com/Memory2314/XuexitongJSFork) | 23 | 油猴 | **明确"去除 AI 答题"**，后台刷课+静音+自动答题，2026-03 仍可用 |
| [SJ-Don/OnlineCourseScript](https://github.com/SJ-Don/OnlineCourseScript) | 6 | 油猴 | 老牌（2020），自动静音、自动跳下一个 |
| [flupke91/chaoxing-study-tool](https://github.com/flupke91/chaoxing-study-tool) | 0 | Node+Playwright | 只负责"用你本机 Edge 打开课程页"，可参考其 URL/`enc` 取法 |
| [fysh1010/chaoxing-script](https://github.com/fysh1010/chaoxing-script) | — | 油猴 | 智能升级版（含 AI 答题，本需求不要 AI） |

**结论**：现成方案够用。若用户坚持"定制 + 一键抓包 + 本地应用"，就自建 Playwright 应用，并**参考**上面脚本的接口调用方式（不必从零逆向）。
